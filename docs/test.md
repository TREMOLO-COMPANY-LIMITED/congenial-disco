# CI通知テスト

このドキュメントは、CI通知の動作確認を行うためのテスト用ページです。

## 目的

- ドキュメントのみの変更でCIが正常に実行されることを確認する
- CI完了時の通知が期待どおり送信されることを確認する
- 通知内容にビルド結果や対象ブランチが含まれることを確認する

## 確認手順

1. このファイルに軽微な変更を加えてPull Requestを作成する。
2. CIが開始され、完了するまで待つ。
3. Slackなどの通知先にCI結果の通知が届くことを確認する。
4. 通知内容が対象Pull RequestとCI結果を正しく示していることを確認する。

## 注意事項

このファイルはCI通知テスト用の説明資料です。アプリケーションの実行時挙動には影響しません。
